Explore and understand this codebase thoroughly. Your goal is to orient yourself with:

1. **Project structure** - Key directories, entry points, and how the code is organized
2. **Architecture** - Major components, how they interact, and design patterns used
3. **Dependencies** - Important libraries, frameworks, and external services
4. **Build/run process** - How to build, test, and run the project
5. **Recent changes** - Look at recent commits to understand current development focus

Create or update memories about the codebase structure so this knowledge persists for future sessions.

Be thorough but efficient. Focus on understanding the big picture and key areas that will be most useful for development work.
