# Benchmarks

This directory contains benchmark results from evaluating Apex against known-vulnerable applications.

## Suites

### [Argus](./argus/)

60-benchmark validation suite purpose-built for evaluating AI pentest tools. Covers single-vulnerability targets, intermediate multi-vuln apps, and multi-step attack chains requiring sequential exploitation. All benchmarks run as Docker Compose stacks.

### [XBEN](./xben/)

Earlier benchmark execution logs from the XBEN suite (pre-Argus). Retained for historical reference.
