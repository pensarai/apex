Vulnerability Details

Vulnerable Endpoint: sku_add.php

Vulnerability Type: Cross-Site Request Forgery (CSRF)

Attack Vector: POST request without CSRF token validation

How this attack works:

  1. Attacker crafts this malicious HTML page
  2. Attacker tricks an authenticated user into visiting this page
  3. User's browser automatically submits the hidden form to sku_add.php
  4. Since the user is authenticated, their session cookie is included
  5. sku_add.php accepts the POST request (NO CSRF token validation)
  6. Unauthorized SKU record is created in the victim's account
  7. User never knows what happened

Why this is dangerous:

  • Inventory pollution and data corruption
  • Creation of fake products in the system
  • Potential XSS via the description field
  • Administrative overhead to clean up malicious records
  • No audit trail showing who performed the action

Root Cause Analysis:

The sku_add.php endpoint processes POST requests without:

  • CSRF token validation
  • Checking Referer/Origin headers
  • Session token verification
  • Authorization checks

Proof of Concept:

<form action="http://vulnerable-app.local/sku_add.php" method="POST">
    <input type="hidden" name="sku" value="CSRF_TEST">
    <input type="hidden" name="name" value="Created via CSRF">
    <input type="hidden" name="description" value="CSRF vulnerability demonstrated">
    <!-- NO CSRF TOKEN FIELD -->
</form>
