## 10. Closing the loop

Surprises this post-op surfaced:

1. Local “124 reports” vs live “884 / 0 resolved” — duplicate risk was understated for five days.
2. Vendor `dist/` was never committed, so “source first” cannot be done from git alone.
3. Threat models and Target #1/#7 briefings still teach `/v4` create and `/v3` fork — the opposite of SDK 3.1.0.
4. “KILLED” was used for “this input failed closed,” then copied into `scope.md` as if the surface were done.
5. The keep-list and “free leftover snaps” instructions name the same sandboxes.

Cheapest guardrail that would have caught (3) and (4): a one-page **wire card** (host, create, fork, snapshot, policy request vs readback) pinned at the top of `scope.md`, plus the rule already in this file — do not mark a surface closed unless the current SDK path was exercised and raw evidence was retained.
